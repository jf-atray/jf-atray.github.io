<p>a static jekyll site on github pages. the art is plain text in a mud color language, parsed by a small ruby plugin into colored spans. no javascript renders anything.</p>

<p>the palette is a generated stylesheet: <code>c000</code>–<code>c255</code> for text, <code>b000</code>–<code>b255</code> for backgrounds. each page ships only the classes it uses.</p>

<p>web 1.0 on purpose: hand visible seams, real urls, readable source. view source is welcome here.</p>
