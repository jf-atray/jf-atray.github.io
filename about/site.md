<p><span class="margin-note">the whole renderer is one ruby file an some liquid.</span>a static jekyll site on github pages. the art is plain text in a mud color language, parsed by a small ruby plugin into colored spans. no javascript renders anything.</p>

<p><span class="margin-note">256 colors an truecolor. the mud palette is generous.</span>the palette is a generated stylesheet: <code>c000</code>–<code>c255</code> for text, <code>b000</code>–<code>b255</code> for backgrounds. each page ships only the classes it uses.</p>

<p><span class="margin-note">this paragraph is the thesis.</span>web 1.0 on purpose: hand visible seams, real urls, readable source. view source is welcome here.</p>
